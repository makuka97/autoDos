README.TXT for the Enhanced CD Installer
========================================

From here you can install the game, change and test your sound card
settings, view this file, or configure other options such as language and
control settings.  We suggest that you first configure and test your sound
settings, set any other options such as low-resolution cutscenes, and then
install the game.  If you want to change your settings without
reinstalling, choose the "save settings and exit" option from the main
menu.

If you are having technical problems, or are interested in more
information about the game, please read the readme.ss file that is on this
CD.  

We hope you enjoy the game!
